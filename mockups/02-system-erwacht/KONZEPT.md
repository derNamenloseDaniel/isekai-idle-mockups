# Mockup 2 — „[System] Erwacht" (LitRPG / Solo-Leveling-HUD)

**Look:** Glas-Hologramm-Panels (Glassmorphism + Backdrop-Blur), Cyan/Violett auf Nachtblau,
Scanlines, [System]-Toast-Nachrichten, Anime-Portrait + Gate-Keyart (FLUX), Fonts
Rajdhani/Exo 2. Das ganze UI *ist* das Isekai-System-Fenster — maximale Trope-Ausnutzung.

## Was das Mockup zeigt

- **Intro als System-Protokoll:** Tod durch Lieferwagen (Truck-kun!), Übertragung nach
  Aethermoor, Ausgleichs-Skill „[Ewige Wiederkehr]" — das Prestige-System *ist* die Story.
- **Statusfenster** (RPG-Anker): Portrait, Klasse, Jäger-Rang F → SSS, Titel — Rang steigt
  durch Gates + Wiedergeburten.
- **Kern-Loop:** 4 Skills als Mana-Zirkel (= Revo-Kreise): [Zirkel des Anfängers],
  [Klingensturm], [Schattenschritt], [Herrscher-Domäne]. Konzentrische SVG-Ringe mit
  pulsierendem Kern zeigen die Rotationen.
- **Level up / Awakening / Rückkehr** = Buy/Ascend/Prestige (5×-Bestätigung als
  „Sicherheitsabfrage des Systems").
- **Gates als Bosse:** E-Rang → C-Rang → S-Rang, Siege entsiegeln Skills.
- **[System]-Toasts** für jedes Event — das charakteristischste UI-Element dieser Richtung.
- **Fernziel:** „Synchronisation: Welten-Gate" → Kapitel 2 «Jenseits des Gates».

## Vorschläge für die Vollversion

1. **Toast-Feed als Feature:** Achievements, Ränge, Drops — alles als System-Meldung mit
   eigener Historie (Log-Tab). Humor-Kanal: das System kommentiert sarkastisch.
2. **Quest-Fenster** (= Challenges): „Tägliche Quest: 10.000 Schritte im Dungeon" —
   Solo-Leveling-Referenz, Regel-Twist-Runs mit Belohnung.
3. **Schatten-Armee** (= Eternity-Zoo): besiegte Bosse als beschworene Schatten mit
   Passiv-Boni — deckungsgleich mit Revo-Animals, aber 100 % Solo-Leveling.
4. **Skilltree als Hologramm-Konstellation** (= Infinity-Baum), Nodes mit Datenblatt-Optik.
5. **Stat-Verteilung:** STR/AGI/INT/VIT-Punkte pro Rückkehr (= Promotion-Pfade).
6. **Steam-Tauglichkeit:** LitRPG/Solo-Leveling-Ästhetik hat riesige Zielgruppe; UI-Look
   ist günstig zu produzieren (CSS statt Illustration) — das artwork-effizienteste Konzept.
7. **Risiko:** Glass-UI + Blur kostet GPU bei schwachen Geräten → Low-FX-Modus einplanen.
   Backdrop-Filter-Interaktion mit Schatten beachten (bekanntes Learning #3).
